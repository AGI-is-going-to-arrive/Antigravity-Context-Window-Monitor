# 监控面板设计规范

[English](../../DESIGN.md) · [中文首页](../../readme_CN.md)

App 和 IDE 共用同一套面板样式。界面优先让用户一眼读到当前会话的数字、范围和测量状态。主要内容区使用中性色，操作入口用钴蓝色，健康状态使用绿、琥珀和红色。组件采用宿主主题、本地字体和等宽数字。

## 颜色与层次

| 用途 | 浅色 | 深色 | 变量 |
| --- | --- | --- | --- |
| 页面背景 | `#FAFBFC` | `#0D1014` | `--ed-bg` |
| 卡片 | `#FFFFFF` | `#14181F` | `--ed-surface` |
| 内嵌区域 | `#F2F4F8` | `#1B212B` | `--ed-surface-well` |
| 悬停背景 | `#E9EEF5` | `#222A36` | `--ed-surface-hover` |
| 进度轨道 | `#E2E7EF` | `#232B38` | `--ed-track` |
| 普通 / 强分隔线 | `#E4E8EF` / `#C8D0DC` | `#232A35` / `#323C4C` | `--ed-border` / `--ed-border-strong` |
| 表单控件边框 | `#8792A4` | `#5A687D` | `--ed-control-border` |
| 主 / 次文字 | `#111318` / `#454D5B` | `#F2F4F8` / `#B6C0CE` | `--ed-ink` / `--ed-ink-secondary` |
| 辅助文字 | `#5A6475` | `#8C98A9` | `--ed-ink-muted` |
| 主操作与键盘焦点 | `#1D4ED8` | `#5B9CF6` | `--ed-accent` |

页面和吸顶栏使用基础背景。卡片用背景色和 1px 边框分组，输入框、表头和分段开关使用内嵌背景。阴影主要用于浮动提示框、账号面板以及分段开关的选中项。控件与背景的对比目标为 3:1，常规文字为 4.5:1。高对比度模式使用宿主与操作系统提供的前景、背景和轮廓色。

配额余量充足时用绿，接近重置前用尽时用琥珀或红。上下文压力的正常区间低于 65%，65% 至低于 80% 提示关注，80% 起提示高压。超过 100% 时保留实际百分比，条形图在边缘截满。未知读数保留空轨道，同时显示文字。费用图四条系列分别为输入（灰蓝）、输出（钴蓝）、缓存（青绿）和思考（紫色），图例保留名称。

## 字体、数字与双语

| 层级 | 参考大小 | 用途 |
| --- | ---: | --- |
| 主读数 | 28px，字重 650 | 上下文占用、主要费用与关键百分比 |
| 页标题 | 24px | 英文可使用本地衬线标题字体，中文使用无衬线字体 |
| 分区 / 行标题 | 15px / 14px | 卡片、模型、会话与工作区 |
| 正文 / 标签 | 13px / 12px | 表格、说明、时间、重置计划 |
| 小标记和代码 | 11–12px | 状态、内部标识、路径和 token 示例 |

中文字体依次使用可用的系统字体，如苹方、冬青黑体、微软雅黑或 Noto Sans CJK。英文标题的字体栈最终回落到 UI 无衬线字体，以保证汉字字形一致。代码使用编辑器等宽字体。数字应用 `font-variant-numeric: tabular-nums lining-nums`，使轮询更新时列宽稳定。

可见双语标签由 `tBiHtml()` 生成，分别设置 `.bi-en`、`.bi-sep`、`.bi-zh` 的层次。分隔符和第二语言使用次要样式，保留文本内容和无障碍名称。纯文本属性使用 `tBi()`。中文标签统一使用「账号」「配额」「费用」「冷启动」「首字延迟」及「模型调用」。

## 布局与控件

- 主阅读区参考宽度 1120px，左右留白随窗口从 14px 到 28px 变化。按 4px 间距组织卡片内部，章节之间保留约 24px。较宽时概览使用两列；较窄时依次排列。320–640px 重点检查搜索、筛选按钮、表格横向滚动和日历七列。
- 顶栏放账号入口、语言、暂停或恢复、刷新、关于与时间。会话选择和锁定控件明确标出当前对象。六个主标签共用一条 2px 的活动指示线；标签具有键盘焦点，切换后内容可立即阅读。
- 常规按钮和输入框高 32px，紧凑工具按钮高 28px。主操作使用主题强调色，次要操作使用中性边框，危险操作使用危险色并保留动词。开关同时显示状态，禁用项可提供原因说明。表单使用明确标签，数值步进的加减按钮和输入框保持整齐。
- 细进度条通常高 6px，堆叠图约 8px。静态卡片、输入控件、小标签、浮层的参考圆角依次为 10px、6px、4px、12px，胶囊进度条使用完整圆角。图标继承文字颜色，操作按钮保留可访问名称。
- 悬停提示可以固定为非模态详情。定位考虑 80%–150% 缩放、窄栏边界和轮询后的触发元素。按 Esc 关闭，仍存在的触发控件重新获得焦点。遵循 `prefers-reduced-motion`，减少或关闭过渡动画。

## 各页面的信息顺序

| 页面 | 首先呈现 | 展开或进一步操作 |
| --- | --- | --- |
| 概览 | 当前会话、上下文双上限、配额和关键指标 | 展开上下文构成、查看成员详情、生成报告和交接提示词 |
| 模型调用 | 调用数、速度、延迟、缓存和最新调用 | 切换解码 / E2E、筛选异常、查看调用明细 |
| 会话 | 搜索、筛选、工作区和会话层级 | 展开成员并检查其概览，定位已注册工作区 |
| 用量与费用 | 日历、工作区用量、参考费用 | 切换汇率与计价模式，编辑单价，导出筛选范围 |
| 模型与配额 | 账号、模型池、5 小时及每周配额 | 展开模型规格、编排设置、积分和套餐细节 |
| 设置 | 版本与更新 | 显示与语言、遥测、货币、悬浮层、备份、诊断及全局规则 |
| 关于 | 版本、项目、许可和入口 | 跳到设置或各功能页 |

原生 HUD 在 App 和 IDE 分别设置，默认 App 开启、IDE 关闭，可选择在概览自动隐藏。可选 CDP 悬浮层按同一会话和数据版本显示上下文；在 Windows 上避开标题栏控件，在分屏中保留聊天输入焦点。IDE 状态栏悬停说明按优先级和可用行数组织，优先保留主要读数及配额。[CDP 操作说明](cdp-overlays.md)

修改样式时先检查浅色、深色、高对比度和三种语言；再检查窄栏至宽屏、键盘导航、减少动画、缺失数据和超限状态。CSS 主题来自 `src/webview-editorial-styles.ts`，App 主题桥接位于 `src/app/theme-adapter.ts`。构建与共享数据约束见[架构说明](architecture.md)。
