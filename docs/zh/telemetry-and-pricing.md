# 遥测、计价与命令行状态栏

[English](../telemetry-and-pricing.md) · [中文首页](../../readme_CN.md)

## 压缩后应该看哪一个数

执行 `/compact` 后，完整检查点记录的是摘要模型生成摘要时读取的旧上下文。概览根据保留的摘要和可用上下文给出**压缩后估算**；证据不足时显示 `—`。之后第一条带用量数据的主模型调用会提供新的实测值。自动压缩上限和原生窗口上限可以不同，切换分母时实际使用的 token 数保持一致。

**模型调用**按调用时间排列能确认时间的记录。「锁定主会话」固定概览的观测对象，等待子智能体期间可能有更新的成员调用。成员元数据未附时间时，插件在本次轮询预算内读取相应 planner 步骤，用步骤索引和调用身份核对时间；仍无法匹配的记录排在有时间的记录之后。手动刷新会重新读取当前会话，步数相同的空闲会话也可刷新。

## 提示词缓存

提示词总量等于新增输入、缓存读取和缓存写入三者之和。服务端上报的复用率达到 70% 时显示热缓存，10% 至低于 70% 为部分命中，低于 10% 为冷缓存。缺少测量时显示未知。

「5 分钟空闲 TTL」是按账号、后端、会话、模型和分支分别维护的本地预测。最近一次有效缓存事件过去 180 秒时提醒，达到 300 秒时提示可能过期。连续两次计时间隔达到 90 秒，或系统时钟向后调整时，原计时失效。模型切换、压缩、提示词修改均可能造成未命中；只有调用记录能说明某次请求实际读取了多少缓存。

## 生成速度、延迟与异常筛选

| 指标 | 计算和显示 |
| --- | --- |
| 解码速度 | 输出 tokens ÷ 流式生成秒数。流式时间不包含首字延迟。 |
| 调用端到端速度 | 输出 tokens ÷（首字延迟 + 流式生成秒数）。工具执行和多智能体调度在这个计时区间之外。 |
| 汇总速度 | 有效样本的输出总量 ÷ 相应耗时之和。样本旁显示覆盖的调用数。 |
| 样本状态 | 正在等首字时显示「等待首字」。少于 16 个输出 tokens 或流式耗时不足 0.3 秒时标为「短样本」。 |

默认异常筛选包括首字延迟 ≥ 5 秒、提示词至少 1,000 tokens 且缓存复用率低于 10%、单次参考费用 ≥ 0.25 美元、上下文 ≥ 80% 或 ≥ 200k，以及错误或重试。

## 双窗口配额

可查看 5 小时、每周或「按剩余较少的窗口」，并切换显示剩余或已用份额。自动模式按每个模型池比较已上报的窗口；仅有一个读数时选该窗口，相同则选 5 小时。界面同时显示所选窗口名称和可用的重置时间。

短期预测使用 45 分钟滚动样本，过滤小于 0.1 个百分点的抖动，并识别配额恢复和重置时间变化。自定义模型或自带密钥的模型单独处理。每周预测按账号、池、窗口和重置时间保存 UTC 小时桶，最多 64 组，每组 336 个。App 与 IDE 的同时观测去重，两小时及以上的离线空档不计入使用速度。至少跨两个本地日历日、有两小时有效活动且观测跨度达到 24 小时，才会给出预测。这种按小时归集的方式可处理夏令时变更。

## 工作区、成员费用与导出

「成员详情 → 打开成员概览」读取该成员自己的数据。整组费用按逻辑调用去重，并显示有调用记录的成员数和未定价调用数。组内会话历史与日历所选周期可以覆盖不同时间段。工作区在记录调用时绑定；失去归属信息的旧记录归入「未归属」。

Markdown、CSV、JSON 使用相同的来源、时区、周起始日、日期范围和筛选条件。日期选择为空时导出空结果。CSV 处理可能被表格软件解释为公式的前缀，Markdown 转义单元格和链接，JSON 保留美元原值、货币、汇率和数据来源。

## 配置只读 agy 状态栏

在 `~/.gemini/antigravity-cli/settings.json` 中配置命令。将示例路径改为本机安装目录的绝对路径。

```json
{
  "statusLine": {
    "command": "node",
    "args": [
      "/Users/<you>/.gemini/config/plugins/antigravity-context-monitor/bin/agy-statusline.mjs",
      "--currency", "USD",
      "--basis", "compaction"
    ]
  }
}
```

支持 `--basis compaction|native`、`--currency`、`--fx-rate`、`--no-color`、`--color`、`--show-title`、`--max-width`、`--timeout-ms`、`--version` 和 `--help`。宽度参数会优先省略尾部可选字段。环境变量包括 `NO_COLOR`、`ACM_CURRENCY`、`ACM_CUSTOM_FX_RATE` 和 `ACM_CONTEXT_BASIS`。脚本只读当前命令行会话传入的标准输入，读取上限为 64 KiB 和 1,500 毫秒，清理终端控制字符后输出一行。缺失指标显示 `—`。[实现架构](architecture.md)
