# Antigravity 监控插件架构

[English](../architecture.md) · [中文首页](../../readme_CN.md)

Antigravity App 通过原生 Sidecar 加载插件，Antigravity IDE 通过 VSIX 加载扩展。两端复用 TypeScript 采集和显示逻辑，各自选择所属宿主的本地后端。可选的 `agy` 命令行状态栏从当前命令行会话的标准输入读取数据。

## 共享模块

| 模块 | 职责 |
| --- | --- |
| `src/core/context-display.ts` | 创建只读的 `PublishedMonitorObservation`，供概览、原生 HUD、CDP 悬浮层及 IDE 状态栏显示。 |
| `src/core/swarm-registry.ts` | 读取成员清单、解析父子关系、调度成员轮询，按逻辑调用标识汇总整组费用。 |
| `src/core/gm-context-fallback.ts` | 按时间、步骤和调用顺序选择生成元数据，排除早于压缩或回退边界的读数。 |
| `src/core/currency.ts` | 定义十种货币的符号、小数位、微额费用与自定义汇率，合计后再舍入。 |
| `src/core/model-catalog-sync.ts`、`pricing-validation.ts` | 归一化宿主模型目录，校验自定义单价与套餐设置。 |
| `src/core/release-security.ts`、`version.ts` | 校验 GitHub 发布资产、SHA-256、解包路径和版本来源。 |
| `src/core/cdp-launcher-core.ts`、`external-url.ts` | 处理平台启动器路径、参数引用和允许打开的外部链接。 |

## 一次读数怎样到达界面

每次发布的观测都带有后端代次、窗口、主会话、当前查看的成员、选择版本和数据版本。上下文字段包含实测模型、用量来源、压缩上限、原生上限以及实际采用的分母。文本可以显示超过 100% 的值，进度条最多填满。速度字段同时保存解码或端到端口径、样本范围、调用标识和速度值。同一观测在各显示位置采用相同的舍入规则。

确认刚创建的零步骤会话显示 0%。证据不足时显示 `—`。完整压缩检查点晚于主模型最近一次测量时，插件用保留的摘要和可用上下文估算压缩后的占用量。下一次有用量数据的主模型调用会恢复实测值。空闲时插件检查轨迹修订信息并定期重读当前会话；手动刷新也会重新请求数据。[遥测与计价](telemetry-and-pricing.md)

## 窗口焦点、主会话锁定和成员详情

显示偏好通过 `state-v1.json` 在本机共享。每个窗口另外维护宿主焦点 `observedHostFocus`、锁定的主会话 `lockedRootId` 和正在查看的成员 `inspectedMemberId`。

1. 锁定时立即记录主会话。若正在查看子成员，先沿父子关系找到主会话。
2. 后台成员活动、空白新对话和短暂缺失的会话列表都保留当前锁定。一次轮询缺少目标时显示等待或不可用，确认删除后才解除该目标。
3. 在成员详情打开概览后，可以用「返回主会话」恢复原目标。
4. 显式选择优先于宿主 SDK 的焦点通知。宿主回调优先于更早发起的查询结果。可选 CDP 仅使用明确的焦点参数，并按焦点修订号确认。

## 成员来源与采集预算

成员关系只读所属宿主配置目录下的 `members.json` 和 `swarm.json`。可用 `ANTIGRAVITY_BRAIN_DIR` 或 `ANTIGRAVITY_DATA_DIR` 指定位置，默认路径是 `~/.gemini/antigravity/brain`。远程 SSH 或 WSL 后端使用其自身的目录。插件检查路径、符号链接和 Windows 联接点，打开文件后复核文件标识。单个文件上限 512 KiB，每次遍历上限 4 MiB、200 个目录和 1.5 秒；部分写入可短暂沿用上一次有效清单。

主会话、直接子智能体、嵌套助手及分支使用不同的关系类型。冲突、孤立成员、未知角色以及协调器缺失会单独标记。调用、活动与轨迹读取共享请求数、总字节数、并发和时间预算。默认预算为 24 次请求、32 MiB、8 秒，最多同时进行 3 次请求。优先读取当前目标和主会话，其余成员轮换读取。成员列表同时显示最近观测时间，以便判断覆盖是否完整。

## 构建、隐私与持久化

- 浏览器端代码独立类型检查，再由 `esbuild` 打包。浏览器包内的内容哈希 `buildId` 用于识别同版本的不同构建。开发依赖在打包阶段使用，插件运行时使用 Node 内置模块。
- IDE 的 VSIX 包含扩展入口、清单、图标和许可文件。App 的 ZIP/TAR.GZ 包含 Sidecar、兼容入口、技能说明和可选状态栏脚本。发布校验清单为 `dist/SHA256SUMS.txt`。当前打包脚本对 VSIX 设置 573,440 字节压缩上限和 1,625,292 字节解压上限，App ZIP 上限为 576,716 字节。
- 独立 Sidecar 先配对，再校验本机回环地址、请求来源、内容类型、凭据和请求体大小。隐私模式在序列化前遮蔽账号和路径；「在文件管理器中显示」只接受宿主已注册的工作区。
- 使用同一本地文件系统和进程命名空间时，App 和 IDE 通过排他文件锁、三方合并和写入回执共享状态；跨机器或网络文件系统同步不在支持范围内。[可选 CDP 悬浮层](cdp-overlays.md)
