# 产品规格

[English](../../PRODUCT.md) · [中文首页](../../readme_CN.md)

Antigravity Context Window Monitor 是以 MIT 协议开源的本地遥测工具。开发者可在编码过程中查看会话上下文、成员活动、模型调用、配额消耗与 API 参考费用。读数直接来自所选宿主。界面同时标识实测、估算、未上报和历史记录。

## 支持的宿主

| 宿主 | 使用方式 |
| --- | --- |
| Antigravity App | 通过桌面应用的 Sidecar 安装。可从插件侧栏打开窄面板或宽屏面板。支持原生 HUD，以及按需启用的输入框上下文环和顶栏悬浮层。 |
| Antigravity IDE | 通过 VSIX 安装。在状态栏查看当前会话，悬停查看摘要，或用 macOS 的 `Cmd+Alt+M`、Windows/Linux 的 `Ctrl+Alt+M` 打开完整面板。 |
| agy CLI | 可选状态栏脚本读取当前 CLI 会话的标准输入。「用量与费用」也能读取本机 CLI 用量日志。 |
| Antigravity SDK | 独立的编程接口，目前没有插件面板集成。 |

App 和 IDE 可在同一台机器上并行运行，使用各自后端采集。通过本地持久化状态共享设置和可合并的用量记录。不同机器及远程环境各自保留本机数据。

## 六个主标签

1. **概览。** 选择会话、锁定主会话、查看成员或返回主会话。上下文卡片显示占用量、压缩上限和原生窗口上限；条形图或点阵可展开各类占用及最大的上下文项。还可复制上下文报告、预览交接提示词，查看双窗口配额、速度、缓存与费用。压缩完成到下一次调用之间会标明估算状态。
2. **模型调用。** 查看实际模型、时间、输入、输出、思考占比、缓存、首字延迟、速度、状态和参考费用。可切换解码与调用端到端速度，筛选高延迟、缓存未命中、高费用、高上下文以及错误/重试。
3. **会话。** 按工作区浏览或搜索会话。多智能体任务按主会话与成员呈现。通过「成员详情」可打开成员自己的概览；文件管理器操作以宿主已注册的工作区为准。
4. **用量与费用。** 日历可在热力图和月视图之间切换，并可按 App、IDE 或 CLI 来源筛选。默认保留 400 天，范围为 30–3650 天。支持工作区排行、整组去重费用、十种显示货币、自定义参考单价、映射与严格计价、套餐参考比较，以及 Markdown、CSV 和 JSON 导出。「未归属」保留无法可靠匹配工作区的旧数据。
5. **模型与配额。** 查看账号实际提供的模型、规格、编排设置、5 小时与每周配额。可选择剩余较少的窗口，并显示已用或剩余百分比。每周活动时长预测需要足够的本地历史，未上报的配额或积分显示不可用。
6. **设置。** 首项是「版本与更新」。这里管理语言、显示密度、原生 HUD、遥测口径、货币、自定义汇率、CDP 启动器、数据备份与诊断，也可编辑 Antigravity 全局规则。顶部的 ⓘ 打开「关于」，可查看版本与功能导航。

## 阅读数据和操作窗口

同一窗口所查看的会话决定上下文读数，后台成员的工作不会改变已经锁定的主会话。模型分配和实际调用模型分别显示。多个成员的直接费用与整组去重费用也分别显示，以便核对来源。当前会话、当前组和账本日期是三种不同的统计范围。

插件通过只读本地遥测获取使用情况。安装、设置、全局规则编辑、导出和更新属于用户主动执行的操作。独立 Sidecar 先配对，隐私模式在输出前遮蔽可能识别用户的信息。插件运行时使用 Node 内置模块，安装不需要修改宿主二进制。[架构与数据边界](architecture.md)

## 显示语言与无障碍

首次打开时跟随系统语言，支持简体中文、英文和双语。窄面板会调整布局并保留用户的语言偏好。浅色、深色及对应的高对比度主题共用交互层级。键盘可以切换标签、操作控件和关闭提示层；重要状态同时使用文字。字体、颜色和面板断点见[设计规范](design.md)。
