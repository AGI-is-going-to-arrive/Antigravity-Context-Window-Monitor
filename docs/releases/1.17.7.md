# Release 1.17.7 — Sidecar Idle Polling & GM Cache Optimization, 1-Click Zero-Patch Persistent CDP Launcher, Overlay Fixes & Updated Plan ROI Presets

## English

### Overview of Changes

- **Idle Polling, ETag Stability & GM Cache Optimization (thanks to [`@reidentify`](https://github.com/reidentify) — [Issue #75](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/issues/75) / [PR #76](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/pull/76) + follow-up hardening — `src/app/sidecar-runtime.ts`, `src/app/sidecar-server.ts`, `src/app/host-bridge.ts`, `src/gm/tracker.ts`, `src/extension.ts`):**
  - **Fixed Sidecar idle-backoff self-lock:** Passive `GET /api/snapshot` polling no longer resets `lastClientActivityMs`. Only genuine user interactions (`?active=1` from pointer/keyboard/visibility/conversation changes or `/api/action`) refresh activity and immediately reschedule sleeping poll timers (with in-flight passive responses guarded against clobbering pending user wakes and visible client idle polling capped cleanly at `≤ 15s`). Added a `CascadeStatus.RUNNING` guard so active generation remains at base cadence (`5s`) while truly idle sessions back off `5s → 30s`.
  - **Eliminated ~4,900+ idle Language Server RPCs/hour (App + IDE parity):** `GMTracker.fetchAll()` now skips unchanged idle active conversations while preserving `RUNNING → IDLE` trailing capture (`justBecameIdle`), tracks settled idle step counts (`_settledIdleStepCounts`) so empty/non-LLM or unrecoverable-timestamp idle conversations stop re-fetching every tick, applies bounded exponential error backoff (`60s → 10m`, cleared on manual Refresh in BOTH App Sidecar and IDE `pollContextUsage(true)`) on transient `GetCascadeTrajectory` errors instead of permanently settling incomplete entries, hardens `inheritEnrichedCallFields()` via `buildGMMatchKey()` + `mergeGMCallEntries()` with strict non-conflicting `executionId` guards to preserve all enriched fields (`model`, `modelDisplay`, `modelSource`, `responseModel`, `modelAccuracy`, `executionModel`, `userMessageAnchors`, prompt/tool metadata, and conversation-level `checkpointSummaries`/`systemContextItems`), protects `RUNNING → IDLE` trailing enrichment against premature mid-stream locking, and skips redundant 6-tick `LS_REVALIDATION_INTERVAL` probes when `lsInfo.source === 'env'`.
  - **Stable ETag & multi-slot minute-bucket `snapshotCache`:** Excluded volatile `meta.pollCount` from `computeSnapshotHash()`, upgraded single-slot `snapshotCache` to a bounded `Map` (max 8) keyed with a 1-minute time bucket (`Math.floor(now / 60_000)`) so simultaneous `AUX_PANE` + `SIDEBAR` views never evict each other while live reset countdowns, Account Ready indicators, and 60s CLI rescans stay fresh; expanded `computeDataSignature()` across all rendered state (incl. `cdpStatus.launcherStatus` & `hostHasDebugFlag`); added missing `bumpStateRevision()` hooks; and added `bumpStateRevision()` in `handleAction()` `finally` to prevent async cache-poisoning races.
- **App CDP Discovery, Floating Overlays, Live Diagnostics (`host_missing_flag`) & 1-Click Zero-Patch Persistent CDP Launcher (`src/app/cdp-launcher.ts`, `src/app/cdp-injector.ts`, `src/app/cdp-overlay-assets.ts`, `src/app/sidecar-types.ts`, `src/webview-settings-tab.ts`, `src/webview-script.ts`, `src/webview-editorial-styles.ts`, `src/webview-panel.ts`, `scripts/install-app-plugin.mjs`):**
  - **1-Click Zero-Patch Persistent CDP Launcher (`src/app/cdp-launcher.ts`, Settings UI + CLI `--setup-cdp-launcher` / `--remove-cdp-launcher`):** Pure Node.js generator with zero external dependencies and zero modification to `/Applications/Antigravity.app` or `app.asar`:
    - **macOS (`~/Applications/Antigravity (CDP).app`):** Native `icon.icns` copy and `LSUIElement=true`; checks exact running Antigravity App PID (strictly ignoring `Antigravity IDE.app` / `Antigravity Tools.app`), prompts with a native user confirmation dialog if running without `--remote-debugging-port`, sends graceful AppleScript quit, and polls up to 15s (`0.25s` interval) until Antigravity's ~5s `before-quit` `language_server` background teardown completely exits before launching with `--remote-debugging-port=0` — eliminating both the 5-second `open -a` race and post-auto-update flag loss.
    - **Windows (`%LOCALAPPDATA%\AntigravityContextMonitor\launch-antigravity-cdp.cmd` + Desktop & Start Menu `.lnk`)** and **Linux (`~/.local/bin/antigravity-cdp` + `~/.local/share/applications/antigravity-cdp.desktop`)**.
  - **Smart host argv discovery, anti-self-attachment, IPv6 fallback & concurrency hardening:** Fixed `selectAntigravityHubTarget()` self-attachment by automatically excluding `ANTIGRAVITY_SIDECAR_WEB_PORT`, `ANTIGRAVITY_SIDECAR_PORT`, standalone listening port (`setListeningPort()` + `addExcludedPort()`), `plugin://` URLs, and sidecar/swarm titles (`Antigravity 监控面板`, `Antigravity Monitor`, `Antigravity Context Monitor`, `swarm`), while preferring `https:` loopback Hub targets and recognizing `Jetski Web`. Added read-only grandparent host process argv inspection (`inspectAntigravityHostProcess`) reporting `host_missing_flag` when Antigravity runs without `--remote-debugging-port`, prepending custom `--user-data-dir` `DevToolsActivePort` paths, and falling back directly to fixed `--remote-debugging-port=<N>` ports. Fixed `ensureConnected()` `createBridgeFn()` error path to `await detachClient(false)` (preventing leaked sockets / backoff bypass); added IPv6 `[::1]` fallback, an in-flight WebSocket mutex, and loopback TCP reachability probing (`127.0.0.1` → `::1`) in `scripts/install-app-plugin.mjs --status` (`cdp.stale` + `cdpLauncher`).
  - **Floating overlay anchoring, WCO, theme, `Open Panel` & live dual-surface Settings sync (`CDP_OVERLAY_SCRIPT_VERSION = '1.17.7-r1'`):** Anchored Top-Right Status Bar cleanly before `[data-testid="toggle-maximize-pane"]` (never splitting `[Fullscreen, Toggle Side Panel]`), removed duplicate Windows WCO spacers in inline mode when `[data-testid="window-controls-reserve"]` is present, and collapsed secondary pills earlier on narrow titlebars. Fixed Composer Floating Ring visibility/hidden-tab re-anchoring and `[data-testid="input-box-bottom-toolbar"]` / `[data-testid="permissions-selector-trigger"]` fallback (handling Material Symbols `Turbokeyboard_arrow_down` ligature and right-group fallback). Wired `Open Panel` to expand collapsed `[data-testid="toggle-aux-sidebar"][aria-expanded="false"]` directly, improved `detectHostTheme()`, wired live `#cdpStatusPill` / `#cdpDiagnosticHint` (incl. `host_missing_flag`) / `#cdpLauncherStatus` / `#cdpSetupLauncherBtn` / `#cdpRemoveLauncherBtn` / `#updateStatusPill` / `#cdpRecheckBtn` / `.cdp-copy-btn` across both App Sidecar and IDE, and fixed IDE toggle-ON to probe CDP immediately (never stuck on stale `disabled`).
- **Updated Subscription Plan ROI Presets (`src/cli-usage-scanner.ts`, `package.json`, `src/webview-settings-tab.ts`, `src/webview-script.ts`, `src/app/sidecar-runtime.ts`, `src/extension.ts`, `src/webview-panel.ts`, `src/webview-document.ts`):**
  - Updated Calendar Subscription Plan ROI presets to **Google AI Pro (`$19.99/mo`)**, **Google AI Ultra 5x (`$99.99/mo`)**, and **Google AI Ultra 20x (`$199.99/mo`)** (plus `custom`), with centralized `normalizeSubscriptionPlanId()` non-destructive migration for legacy `'google-ai-ultra'` selections (preserving historical saved monthly fees such as `$249.99`) and dynamic `#subscriptionFeeInput` placeholder syncing.

### 安装与升级

#### 给任意 AI 智能体的一句话安装 / 升级（`AGENTS.md` — 推荐）

直接复制发送给任意 AI 编程助手：

或直接运行零克隆命令行一键安装（自动校验 `SHA256SUMS.txt`）：
- **macOS / Linux：** `curl -fsSL https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs -o /tmp/acm-install.mjs && node /tmp/acm-install.mjs --from-github && rm -f /tmp/acm-install.mjs`
- **Windows（PowerShell）：** `$f = Join-Path $env:TEMP 'acm-install.mjs'; irm 'https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs' -OutFile $f; node $f --from-github; Remove-Item $f -Force`
- **本地仓库升级：** `node scripts/install-app-plugin.mjs --upgrade`（macOS/Linux：`./scripts/install-app-plugin.sh --upgrade`；Windows：`.\scripts\install-app-plugin.ps1 --upgrade`），随后运行 `node scripts/install-app-plugin.mjs --status --check-remote` 验收。

#### 面板内一键自更新与手动压缩包安装（Antigravity App）

1. **面板内自更新（v1.17.6+）：** 打开**设置 → 更新**或**关于 → 版本与更新**，点击**检查更新**并点击**立即升级**。原子替换完成后，打开 `[Antigravity Context Monitor](customization://antigravity-context-monitor)` 将插件**关闭再重新开启**即可安全加载新运行时（绝不强杀正在运行的 Antigravity 会话）。
2. **手动压缩包安装：** 下载 `antigravity-context-monitor-app-1.17.7.zip`（macOS / Windows / Linux）或 `antigravity-context-monitor-app-1.17.7.tar.gz`（macOS / Linux）与 `SHA256SUMS.txt`，核对 SHA-256 后解压得到 `antigravity-context-monitor/` 并执行 `agy plugin install ./antigravity-context-monitor`（或直接解压至 `~/.gemini/config/plugins/` 或 `%USERPROFILE%\.gemini\config\plugins\`）。

#### 可选 CDP 桌面悬浮层与一键持久化启动器（严格按需开启，零二进制修改）

核心 `AUX_PANE`、`SIDEBAR` 与**面板顶部紧凑 HUD** 均 100% 原生工作，不依赖 CDP。如需启用输入框悬浮环或右上角状态条：

- **推荐方案（一键持久化，永久免疫自动更新丢参）：** 在**设置 → 悬浮层与 CDP** 点击**一键生成持久化启动器**（或运行 `node scripts/install-app-plugin.mjs --setup-cdp-launcher`），自动生成 `~/Applications/Antigravity (CDP).app`（macOS）、桌面与开始菜单 `.lnk`（Windows）或 `~/.local/share/applications/antigravity-cdp.desktop`（Linux）。
- **手动终端重启：**
  1. **务必先完全退出 Antigravity App**（macOS 按 `Cmd+Q` 后请等待约 5 秒让后台 `language_server` 彻底清理完成——旧进程未完全退出前运行 `open -a` 会静默忽略 `--args`；Windows / Linux 关闭所有窗口及托盘图标）。
  2. **使用 `--remote-debugging-port=0` 重新启动：**
     - **macOS（无竞态等待并启动）：** `while pgrep -f '^/Applications/Antigravity\.app/Contents/MacOS/Antigravity($| )' >/dev/null; do sleep 0.5; done; open -a "/Applications/Antigravity.app" --args --remote-debugging-port=0`
     - **Windows（PowerShell）：** `& "$env:LOCALAPPDATA\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Windows（CMD / 快捷方式目标）：** `"%LOCALAPPDATA%\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Linux：** `antigravity --remote-debugging-port=0`
  3. 打开**设置 → 悬浮层与 CDP** 点击**重新检测**。

下载 `antigravity-context-monitor-1.17.7.vsix`（对照 `SHA256SUMS.txt` 核对校验和），在命令面板（`Cmd+Shift+P` / `Ctrl+Shift+P`）执行 **Extensions: Install from VSIX...** 或命令行执行：
