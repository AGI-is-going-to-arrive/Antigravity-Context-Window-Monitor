# Release 1.17.7 — Sidecar Idle Polling & GM Cache Optimization, CDP Discovery & Floating Overlay Fixes

## English

### Overview of Changes

- **Idle Polling, ETag Stability & GM Cache Optimization (thanks to [`@reidentify`](https://github.com/reidentify) — [Issue #75](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/issues/75) / [PR #76](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/pull/76) + follow-up hardening — `src/app/sidecar-runtime.ts`, `src/app/sidecar-server.ts`, `src/app/host-bridge.ts`, `src/gm/tracker.ts`):**
  - **Fixed Sidecar idle-backoff self-lock:** Passive `GET /api/snapshot` polling no longer resets `lastClientActivityMs`. Only genuine user interactions (`?active=1` from pointer/keyboard/visibility/conversation changes or `/api/action`) refresh activity and immediately reschedule sleeping poll timers (with in-flight passive responses guarded against clobbering pending user wakes and visible client idle polling capped cleanly at `≤ 15s`). Added a `CascadeStatus.RUNNING` guard so active generation remains at base cadence (`5s`) while truly idle sessions back off `5s → 30s`.
  - **Eliminated ~4,900+ idle Language Server RPCs/hour:** `GMTracker.fetchAll()` now skips unchanged idle active conversations while preserving `RUNNING → IDLE` trailing capture (`justBecameIdle`), tracks settled idle step counts (`_settledIdleStepCounts`) so empty/non-LLM or unrecoverable-timestamp idle conversations stop re-fetching every tick, applies bounded exponential error backoff (`60s → 10m`, cleared on manual Refresh) on transient `GetCascadeTrajectory` errors instead of permanently settling incomplete entries, hardens `inheritEnrichedCallFields()` via `buildGMMatchKey()` + `mergeGMCallEntries()` with strict non-conflicting `executionId` guards to preserve all enriched fields (`model`, `modelDisplay`, `modelSource`, `responseModel`, `modelAccuracy`, `executionModel`, `userMessageAnchors`, prompt/tool metadata, and conversation-level `checkpointSummaries`/`systemContextItems`), protects `RUNNING → IDLE` trailing enrichment against premature mid-stream locking, and skips redundant 6-tick `LS_REVALIDATION_INTERVAL` probes when `lsInfo.source === 'env'`.
  - **Stable ETag & multi-slot minute-bucket `snapshotCache`:** Excluded volatile `meta.pollCount` from `computeSnapshotHash()`, upgraded single-slot `snapshotCache` to a bounded `Map` (max 8) keyed with a 1-minute time bucket (`Math.floor(now / 60_000)`) so simultaneous `AUX_PANE` + `SIDEBAR` views never evict each other while live reset countdowns, Account Ready indicators, and 60s CLI rescans stay fresh; expanded `computeDataSignature()` across all rendered state (background trajectories, `cachedUserInfo`/credits/account snapshots, `cachedQuotaSummary`, `cachedOrchestratorSettings`, GM summary fields, `activityChanged`, `dailyLedger` active+settled totals, `cachedCliDays` content fingerprint, `cdpStatus` incl. `diagnosticCode`/`targetTitle`/`discoveredPort`/`portFilePath`, and `updateStatus`); added missing `bumpStateRevision()` hooks (expired-pool baseline, cycle settlement, archival); and added `bumpStateRevision()` in `handleAction()` `finally` to prevent async cache-poisoning races.
- **App CDP Discovery, Floating Overlays & Live Diagnostics Fix (`src/app/cdp-injector.ts`, `src/app/cdp-overlay-assets.ts`, `src/app/sidecar-types.ts`, `src/webview-settings-tab.ts`, `src/webview-script.ts`, `src/webview-editorial-styles.ts`, `src/webview-panel.ts`, `scripts/install-app-plugin.mjs`):**
  - **Target discovery anti-self-attachment, IPv6 fallback & concurrency mutex:** Fixed `selectAntigravityHubTarget()` self-attachment by automatically excluding the sidecar's own listening ports (`ANTIGRAVITY_SIDECAR_WEB_PORT`, `ANTIGRAVITY_SIDECAR_PORT`, and standalone listening port via `setListeningPort()` + `addExcludedPort()`), `plugin://` URLs, and sidecar/swarm titles (`Antigravity 监控面板`, `Antigravity Monitor`, `Antigravity Context Monitor`, `swarm`), while preferring `https:` loopback Hub targets and recognizing `Jetski Web`. Added `AGY_BROWSER_ACTIVE_PORT_FILE` precedence (custom `--user-data-dir`), IPv6 `[::1]` fallback on `ECONNREFUSED` in `fetchCdpTargets()`, an in-flight WebSocket mutex serializing `ensureConnected`/`syncToHub`/`setToggles`/`recheck`/`dispose`, and loopback TCP reachability probing (`127.0.0.1` → `::1`) in `scripts/install-app-plugin.mjs --status` (`inspectDevToolsActivePort()`) to detect stale `DevToolsActivePort` files (`cdp.stale: true`).
  - **Floating overlay anchoring, WCO, theme & `Open Panel` (`CDP_OVERLAY_SCRIPT_VERSION = '1.17.7-r1'`):** Anchored Top-Right Status Bar cleanly before `[data-testid="toggle-maximize-pane"]` (never splitting `[Fullscreen, Toggle Side Panel]`), disabled duplicate Windows WCO spacers in inline mode when `[data-testid="window-controls-reserve"]` is present, and collapsed secondary pills earlier on narrow titlebars / open aux panes. Fixed Composer Floating Ring visibility/hidden-tab re-anchoring and `[data-testid="input-box-bottom-toolbar"]` / `[data-testid="permissions-selector-trigger"]` fallback (handling Material Symbols `Turbokeyboard_arrow_down` ligature and right-group fallback). Wired `Open Panel` to expand collapsed `[data-testid="toggle-aux-sidebar"][aria-expanded="false"]` directly in addition to bridge notification, and improved `detectHostTheme()` (`theme-light`/`theme-dark`/`dark-theme`/`data-agy-theme`/`colorScheme`).
  - **Live Settings diagnostics & Quit-first cross-platform launch guide:** Added structured `CdpDiagnosticCode` (`disabled`, `missing_port_file`, `port_unreachable`, `no_hub_target`, `ws_error`, `eval_error`, `connected`) + `portFilePath` / `discoveredPort`; wired live DOM updates for `#cdpStatusPill`, new bilingual `#cdpDiagnosticHint`, and `#updateStatusPill` across `syncSettingsControls`, `cdpStatusResult`, `updateCheckResult`, `updateTabs`, and `acm:snapshot`; added a **Recheck CDP** button (`#cdpRecheckBtn`, `recheckCdp` wired on both App Sidecar and IDE read-only loopback probe); and unified Quit-first cross-platform CDP launch guides across Settings, CLI (`--print-cdp-guide`), README, `AGENTS.md`, and `SKILL.md` (explicit `Cmd+Q` / full exit first, macOS `/Applications/Antigravity.app`, Windows PowerShell + CMD/Shortcut syntax, Linux, and auto-update flag-loss reminder).

### 安装与升级

#### 给任意 AI 智能体的一句话安装 / 升级（`AGENTS.md` — 推荐）

直接复制发送给任意 AI 编程助手：

> 请阅读 `https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor` 中的 `AGENTS.md`，为我的 Antigravity App 安装或升级 Antigravity Context Monitor。

或直接运行零克隆命令行一键安装（自动校验 `SHA256SUMS.txt`）：
- **macOS / Linux：** `curl -fsSL https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs -o /tmp/acm-install.mjs && node /tmp/acm-install.mjs --from-github && rm -f /tmp/acm-install.mjs`
- **Windows（PowerShell）：** `$f = Join-Path $env:TEMP 'acm-install.mjs'; irm 'https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs' -OutFile $f; node $f --from-github; Remove-Item $f -Force`
- **本地仓库升级：** `node scripts/install-app-plugin.mjs --upgrade`（macOS/Linux：`./scripts/install-app-plugin.sh --upgrade`；Windows：`.\scripts\install-app-plugin.ps1 --upgrade`），随后运行 `node scripts/install-app-plugin.mjs --status --check-remote` 验收。

#### 面板内一键自更新与手动压缩包安装（Antigravity App）

1. **面板内自更新（v1.17.6+）：** 打开**设置 → 更新**或**关于 → 版本与更新**，点击**检查更新**并点击**立即升级**。原子替换完成后，打开 `[Antigravity Context Monitor](customization://antigravity-context-monitor)` 将插件**关闭再重新开启**即可安全加载新运行时（绝不强杀正在运行的 Antigravity 会话）。
2. **手动压缩包安装：** 下载 `antigravity-context-monitor-app-1.17.7.zip`（macOS / Windows / Linux）或 `antigravity-context-monitor-app-1.17.7.tar.gz`（macOS / Linux）与 `SHA256SUMS.txt`，核对 SHA-256 后解压得到 `antigravity-context-monitor/` 并执行 `agy plugin install ./antigravity-context-monitor`（或直接解压至 `~/.gemini/config/plugins/` 或 `%USERPROFILE%\.gemini\config\plugins\`）。

#### 可选 CDP 桌面悬浮层启动指南（严格按需开启，零二进制修改）

核心 `AUX_PANE`、`SIDEBAR` 与**面板顶部紧凑 HUD** 均 100% 原生工作，不依赖 CDP。如需启用输入框悬浮环或右上角状态条：

1. **务必先完全退出 Antigravity App**（macOS 按 `Cmd+Q`；Windows / Linux 关闭所有窗口及托盘图标——macOS 下若应用仍在运行，`open -a` 会静默忽略 `--args`）。
2. **使用 `--remote-debugging-port=0` 重新启动：**
   - **macOS：** `open -a "/Applications/Antigravity.app" --args --remote-debugging-port=0`
   - **Windows（PowerShell）：** `& "$env:LOCALAPPDATA\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
   - **Windows（CMD / 快捷方式目标）：** `"%LOCALAPPDATA%\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
   - **Linux：** `antigravity --remote-debugging-port=0`
3. 打开**设置 → 悬浮层与 CDP** 点击**重新检测**。*（提示：Antigravity 自动更新重启后会丢弃启动参数，更新后请先完全退出再重新带参启动。）*

#### Antigravity IDE（VSIX 扩展 — macOS / Windows / Linux / WSL）

下载 `antigravity-context-monitor-1.17.7.vsix`（对照 `SHA256SUMS.txt` 核对校验和），在命令面板（`Cmd+Shift+P` / `Ctrl+Shift+P`）执行 **Extensions: Install from VSIX...** 或命令行执行：

```bash
antigravity-ide --install-extension antigravity-context-monitor-1.17.7.vsix --force
```

重载 IDE 窗口并在扩展详情或**关于**页确认版本为 **1.17.7**（也可通过 [Open VSX](https://open-vsx.org/extension/AGI-is-going-to-arrive/antigravity-context-monitor) 安装与自动更新）。
