# Release 1.17.3 — Orchestrator Settings, Official Pricing, Hover Tooltip Overhaul & Backend Discovery Fix

## English

### Overview of Changes

- **Backend discovery fix (`Context: Unavailable` / `agy` v1.5.14+ compatibility):** Replaced the single-endpoint `GetUnleashData` CSRF probe (which began returning HTTP 404 after `agy` v1.5.14 / LS 2.34.0 removed `GetUnleashData`) with a resilient multi-endpoint probe chain (`GetStatus → GetUnleashData → GetUserStatus`) in `src/discovery.ts` that treats HTTP 404/501 as unsupported-endpoint fallback rather than invalid CSRF. Added `daemon/hub_<port>.json` and direct-hint discovery fallback, hardened cross-platform loopback parsing across Windows (`powershell.exe` UTF-8 + `Get-CimInstance` + `netstat` + `localhost`), macOS (`/usr/sbin/lsof`), Linux (`ps -axww` + `/usr/sbin/ss`), and IPv6 (`[::1]`), and tightened `isSameBackendConnection` / `doesConnectionMatchActiveHint` (`src/backend-connection.ts`) so backend restarts or port/protocol/CSRF rotations trigger immediate reconnect.
- **Custom Orchestrator Mode, live Orchestrator Settings & 512K Gemini 4 catalog:** Added live **Orchestrator Settings** discovery via `JetboxSubscribeToState` (Connect streaming frame 1, `src/rpc-client.ts`) paired with `GetMendelFlags` (`orchestrator-model-roles`), surfacing the active **Orchestrator Model** and **Executor Model** (Default vs Custom/Pinned, plus eligible Orchestrator/Executor families) in **Models** (`src/webview-models-tab.ts`), cross-pool `Planner → Executor` route pills in **Overview** (`src/webview-overview-tab.ts`), and **Orchestrator Split** breakdowns in the Status Bar hover tooltip (e.g., `Claude Opus 5.5` + `Gemini 4 Hydrogen`, `Gemini 4 Neon` + `Claude Sonnet 5.5`). Aligned `Extra High` / `超高` thinking-effort labels across Gemini 4 Neon & Hydrogen, updated Gemini 4 & Orchestrator checkpointer compression limits to `512,000`, registered `M669` (`Gemini 4 Hydrogen (Orchestrator)`), `M530`/`M531` (`Gemini 4 Hydrogen (Tiered High / Tiered XHigh)`), and `M578` (`Gemini 4 Hydrogen (Sonar)`), and surfaced amber GPT-OSS 120B `Notice` sunset badges across **Models**, **Profile**, and hover alerts.
- **Official model pricing (verified 2026-11-22, USD):** Added official `Gemini 4 Neon` flat-1M pricing (`$3.00` input / `$15.00` output & thinking / `$0.15` cache read per 1M tokens, with automatic zero-cost ledger reconciliation/backfill for historical calls), corrected `Claude Sonnet 5.5` cache read pricing (`$0.20 → $0.10`), bounded the `Gemini 3.6 Flash` intro schedule to `[2026-08-13, 2027-01-01)`, added 45-day upcoming scheduled rate-change countdown banners in **Cost** and Hover Tooltip (Carbon/Argon `2026-12-01` 2× standard; Flash `2027-01-01` 2× standard), enforced deterministic unpriced guards on undated cutover calls and unpriced/internal models (`M537`, `M667`, `M681`, `M669`, `M578`, `M21` — never fabricating `$0.00`), added USD API reference price rows on **Models** spec cards, and consolidated hardened USD cost, savings, and per-1M rate formatting helpers in `src/pricing-store.ts` (all estimated costs displayed strictly in USD across **Overview**, **GM Data**, **Cost**, **Models**, **Calendar**, **Settings**, and Status Bar/Hover).
- **Dual-Window Quota (`5-Hour` + `Weekly`):** Integrated `RetrieveUserQuotaSummary` (`src/quota-tracker.ts`, `src/model-quota.ts`) to display synchronized **5-Hour** and **Weekly** remaining quota meters and reset countdowns across **Overview**, **Models**, **Profile**, and Status Bar Hover Tooltip — with floored sub-100% precision (`99.3%` instead of misleading `100%`, `<1%` floor instead of `0%`), Planner/Executor pool attribution, and graceful 5h-only fallback when weekly data is absent.
- **Priority-tiered Hover Tooltip overhaul & GM Data Recent Calls Ledger:** Rebuilt Status Bar hover rendering on `src/tooltip-budget.ts` (`P0`–`P5` zoom-aware line budgets across `compact`, `auto`, and `full` densities with protected `P0` `Quota remaining` compaction so quota never disappears), adding the **Latest Call** 4-column micro-table (Fresh In, Output + thinking %, Cache Hit %, Cost, TTFT & Total Latency, noise-gated Speed, Status), **Session & Today Cost** + positive Cache Savings + Effective Blended Input Rate, **Orchestrator Split**, event alerts (rate-change countdown, model sunset notice, retry waste, AI credits), 1-click allowlisted footer links (`Overview · Activity · Cost · Models · Settings · Refresh`), and opt-in `statusBar.showSessionCost` (default `false`, USD preview `$0.27`). Added the collapsible, keyboard-accessible **Recent Calls Ledger** (`#recentCallsLedger`, latest 20 calls) in **GM Data**, dynamic `package.json` version pill in **About**, and WCAG 2.1 AA keyboard-focusable horizontal scroll region (`tabindex="0" role="region"` on `.recent-calls-table-wrap`).
