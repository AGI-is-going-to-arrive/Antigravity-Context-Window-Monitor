# Release 1.18.0 — Unified Observation & Swarm Tracking (D9), 6-Tab Shell & App Onboarding, Hardened Global Rules, Huge-Session Recovery (#79) & Zero-Dep `esbuild` Bundles

## English

### Overview of Changes

The App Sidecar and IDE now show local swarm members even when the host omits a worker from its session list. Expand **Member details** to see its reported state. **Open member overview** requests the selected member’s measurements and keeps the main conversation available through **Back to Main**. Usage & Cost shows call-record coverage and distinguishes the current group’s session history from the selected ledger period. Workers with missing call records or unpriced calls are labeled accordingly.

Overview keeps the main readings visible and folds context details. **Set credits expiry day** takes you to the current account’s expiry field. **Version & Updates** opens at the top of Settings, and About links to it. In Models & Quotas, model specifications expand individually for comparison. Account plan parameters display values reported by the host. Select **Lower remaining quota** to see which available window has less headroom, for example **Weekly quota remaining 71%**.

#### 1. Multi-Agent / Swarm Tracking, Unified Immutable Observation & 3-Field Root Lock (D9)
- **Single Immutable `PublishedMonitorObservation` (`src/core/context-display.ts`):** Eliminates cross-surface percentage, denominator, and speed drift across **Overview**, **Native Ambient HUD**, **CDP Topbar**, **CDP Composer Ring**, and **IDE Status Bar**. Every surface rendering the same `(subjectCascadeId, dataRevision)` projects from one deeply-frozen observation carrying `backendEpoch`, `windowId`, `rootCascadeId`, `subjectCascadeId`, `subjectKind` (`main` | `worker` | `subagent`), `measuredModel`, `tokenSource`, both limits with explicit provenance (`compactionLimit` & `nativeLimit`), `requestedBasis` vs `actualBasis`, un-clamped overflow text (`primaryPctRaw`) with clamped bar geometry (`0–100%`), active-axis markers (`200k` / `Compaction`), and speed sample identity. Confirmed zero-step fresh sessions render clean `0%` without stale speed/cost samples; incomplete readings render `—`.
- **Per-Window 3-Field Anti-Hijack Lock State Machine (`src/conversation-selector.ts`):** Separates shared cross-host preferences (`AppSettings`) from per-window `{ observedHostFocus, lockedRootId, inspectedMemberId }` scoped to `{ backendEpoch, windowId }`. When locked, `lockedRootId` strictly outranks all passive inputs (blank-new-chat, unseen host IDs, child-only inventories, `SIDEBAR` empty focus, and background worker churn). Enabling Lock captures the root synchronously (walking up from any inspected worker). Inspecting a worker sets `inspectedMemberId` without altering `lockedRootId`, displays a pinned inspection banner, and restores the saved root in one click via **Back to Main**. Transient omissions render `Pending/Unavailable` rather than prematurely marking conversations deleted; a non-intrusive **Retarget** hint handles split-pane new mains in unlocked mode.
- **Authoritative Read-Only `SwarmRegistry` & Fair-Budget `SwarmPollScheduler` (`src/core/swarm-registry.ts`):** Reads strictly allowlisted manifest metadata (`members.json` / `swarm.json` only — never reads `board.jsonl`, `transcript.jsonl`, `plan.json`, `steps/`, or prompt bodies, and never writes `.system_generated/swarm/`). Enforces safe single-segment `cascadeId` checks, host/profile brain-root scoping (preventing Remote-SSH/WSL local-brain bleed), ancestor symlink/junction checks, `lstat`+`open`+`fstat` identity verification, `512 KB` streaming file cap, bounded sweep budgets with continuation cursors, and partial-JSON grace TTL. Explicitly handles nested sub-swarms, forks, orphans, cycles, conflicting manifests, duplicate names, and unknown roles. Unified per-backend scheduling (`<=3` concurrency) guarantees capacity for Coordinator + inspected member, gives terminal/killed members one final refresh, and fairly round-robins 20+ active members while separating direct worker cost from deduplicated inclusive group totals.
- **Unified GM Context Fallback (`src/core/gm-context-fallback.ts`) & Branch-Scoped Rewind Peak:** Replaces App vs IDE fallback divergence with normalized numeric timestamp + step/call order comparison that rejects stale pre-compaction/pre-rewind samples, and scopes rewind peak tracking per branch so forks never stick in `estimated_rewind`.

#### 3. Huge-Session Suffix Recovery (Issue #79) & Windows `EBUSY` Updater Hardening
- **Bounded Suffix Binary-Search Recovery (`src/tracker.ts`, `src/rpc-client.ts`, `src/context-breakdown.ts` — crediting `@GHTGXL`, Issue #79):** On Antigravity v2.34+ hubs where `GetCascadeTrajectorySteps` can return all remaining steps and trip the `50 MiB` RPC cap or poll byte budget on `>50 MB` conversations (and on paginated `>1,200`-step conversations that previously exhausted the poll request cap), `fetchTrajectorySteps()` now reserves tail request/byte headroom, immediately drops oversized streaming HTTP buffers before OOM (`rpc-client.ts`), and runs bounded (`<=8` probes) suffix binary-search & fine-grained tail recovery (`recoverOversizeSuffix()`). Normalizes missing `stepIndex` and threads `suffixStartOffset` into `parseContextBreakdown`, `detectCompactionCheckpoints`, and `attributeSteps`, while `activity/tracker.ts` preserves `stepCount` on budget-rejected reads so no steps are silently skipped.
- **Windows `EBUSY` Transactional Self-Updater & Installer (`src/app/plugin-updater.ts`, `src/cli/install-app-plugin-entry.ts`):** Adds bounded retry backoff for Windows `EBUSY`/`EPERM`/`EACCES` file locks, locked-CWD in-place sync fallback, mandatory `validateExtractedPluginBundle()` verification (`sidecar-bundle.js`, `sidecar-server.js`, `sidecar-runtime.js`, `sidecar.json`) before deleting backups or completing rollbacks, case-insensitive relative-path sets on `win32`/`darwin`, and safe `pruneEmptyDirs`.
