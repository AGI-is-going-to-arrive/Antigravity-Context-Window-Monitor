# Release 1.17.5 — Antigravity App Native Plugin, Context Breakdown & Dual-Surface Hardening

## English

### Overview of Changes

- **Native Antigravity App (Desktop 2.0+ Sidecar Plugin):** Shipped full first-class support for Antigravity App alongside Antigravity IDE (`app-plugin/`, `src/app/`, `scripts/package-app-plugin.mjs`, `scripts/install-app-plugin.{mjs,sh,ps1}`):
  - **Dual UI entrypoints + companion Skill (`app-plugin/sidecars/context_monitor/sidecar.json`, `app-plugin/skills/context-monitor/SKILL.md`):** Exposes both a compact side panel (`AUX_PANE` at `/`) and a full-width dashboard (`SIDEBAR` at `/full`), plus the `context-monitor` Skill (`sidecar://antigravity-context-monitor/context_monitor/`). Executes directly on Antigravity App's bundled Node runtime (`v24.22.0`) with **zero external npm runtime dependencies**, **zero LLM tool-schema token overhead**, and **zero `app.asar` patching or CDP hacks**.
  - **Shared zero-`vscode` document engine & live Sidecar runtime (`src/webview-document.ts`, `src/app/sidecar-runtime.ts`, `src/app/sidecar-server.ts`, `src/app/host-bridge.ts`, `src/app/theme-adapter.ts`):** Extracted the pure 9-tab Studio Telemetry Ledger renderer (`buildMonitorDocumentHtml` / `buildMonitorTabsPayload`) shared by IDE and App Sidecar; implemented the loopback HTTP / `sidecar_sdk` server (`/`, `/full`, `/api/health`, ETag-diffed `/api/snapshot`, `/api/action`, `/assets/images/*.png`), browser-side visibility-gated ETag poller and `acquireVsCodeApi` bridge (`host-bridge.ts`), full `dark`/`light`/`hc`/`hc-light` host CSS token mapping (`theme-adapter.ts`), and cross-platform zero-dependency `.zip` / `.tar.gz` packager and installers.
- **Context Composition Breakdown & Dual-Cap Clarity (`src/context-breakdown.ts`, `src/webview-overview-tab.ts`):** Added semantic category attribution across 9 buckets (`system`, `rules/skills`, `plugins/MCP`, `subagents`, `user`, `assistant/thinking`, `tools`, `media/files`, `other`) with an interactive **Bar View ↔ 20×5 (100-cell) Dot Matrix** toggle, interactive `<ul class="ctx-legend">` cross-highlighting, **Dual-Cap** readout (`Effective Budget` vs `Native Ceiling`), honest measurement badges (**Measured**, **Estimated (Post-Compaction)**, **Estimated (Rewind)**, **Awaiting Generation**), compaction saved-token chips, collapsible **Top 5 Largest Items**, and one-click **Copy `/context` Report** & **Copy Handoff Prompt** actions.
- **Header Conversation Switcher & Lock to Main Agent (`src/conversation-selector.ts`, `src/webview-document.ts`):** Added the compact Masthead Context Bar across both App and IDE surfaces to stay on **Follow Active** or manually pin any trajectory, toggle **Lock to Main Agent** (subagent-burst immune), inspect surface (`Antigravity App` / `Antigravity IDE`) and stale-cache status, and clear stale context telemetry cleanly on conversation switches (`clearActiveContextTelemetry()`).
- **Turn-Level Cache Diagnostics (`src/turn-diagnostics.ts`, `src/activity-panel.ts`):** Added **Last-Turn vs Session Cache Hit** comparison, **Cold (`<10%`) / Partial (`10%–<70%`) / Warm (`≥70%`) Start** classification pills, and per-turn **`+Δ` net context growth** (plus compaction/rewind drop indicators) inside **GM Data**.
- **Quota Burn-Rate Runway, Stale-Safe Fallback & `custom-*` Model Isolation (`src/quota-runway.ts`, `src/webview-overview-tab.ts`, `src/webview-models-tab.ts`):** Added rolling 45-minute jitter-filtered quota burn-rate prediction (`Safe before reset`, `Est. exhaust in ...`, `Quota exhausted`, `Quota recently recovered`), stale-safe cached telemetry retention (`Cached / Stale` banner with timestamp during transient local RPC errors), and automatic `custom-*` / BYOK / local model isolation suppressing irrelevant Google quota pool alerts.
- **Concurrent App + IDE Persistence, Unified Discovery & Accessibility Hardening (`src/durable-state.ts`, `src/discovery.ts`, `src/i18n-core.ts`):** Added cross-platform atomic `O_CREAT | O_EXCL` lockfile protection (`state-v1.json.lock`, `0o600` on POSIX, 5s stale-lock recovery, Windows NTFS `EPERM`/`EACCES`/`EBUSY` contention retry, 3-way object/account-snapshot merge, and `_hasUnnotifiedExternalChanges` tracking) to `DurableState` so concurrent App + IDE runs never clobber shared history; unified App + IDE surface-isolated backend discovery (`ANTIGRAVITY_LS_ADDRESS`, surface-classified `daemon/hub_<port>.json`, Linux `/proc/<pid>` fallback, macOS/Windows/WSL hardening); decoupled pure zero-`vscode` `i18n-core.ts`; and closed every WCAG 2.1 AA contrast, `<title>`, `#privacyToggle` WCAG 2.5.3 `label-content-name-mismatch`, semantic list ARIA, and focusable scroll-region check.

### Installation

#### Antigravity App (Desktop 2.0+ Native Sidecar Plugin — macOS / Windows / Linux)

1. Download `antigravity-context-monitor-app-1.17.5.zip` (macOS / Windows / Linux) or `antigravity-context-monitor-app-1.17.5.tar.gz` (macOS / Linux) from the release assets below.
2. Extract the archive (produces `antigravity-context-monitor/`), then install via `agy plugin install ./antigravity-context-monitor` — or extract directly into `~/.gemini/config/plugins/` (macOS/Linux) or `%USERPROFILE%\.gemini\config\plugins\` (Windows).
   - From a source checkout, you can also run `npm run compile && node scripts/package-app-plugin.mjs` followed by `node scripts/install-app-plugin.mjs --install` (`./scripts/install-app-plugin.sh --install` on macOS/Linux, `.\scripts\install-app-plugin.ps1 --install` on Windows).
3. In Antigravity App, open **Customizations → Installed** (`customization://antigravity-context-monitor`), verify **Antigravity Context Monitor** and its **Context Monitor** sidecar are enabled (toggle Disable → Enable if upgrading), and open via the side panel **`+`** menu (`AUX_PANE`), **Plugins → Context Monitor** in the left sidebar (`SIDEBAR`), or `sidecar://antigravity-context-monitor/context_monitor/`.

#### Antigravity IDE (VSIX Extension — macOS / Windows / Linux / WSL)

Use **Extensions: Install from VSIX...** (`Cmd+Shift+P` on macOS / `Ctrl+Shift+P` on Windows & Linux) to select `antigravity-context-monitor-1.17.5.vsix` (or run `antigravity-ide --install-extension antigravity-context-monitor-1.17.5.vsix --force`), then reload the IDE window and confirm **1.17.5** in extension details or **About**.

### 安装

#### Antigravity App（桌面版 2.0+ 原生 Sidecar 插件 — macOS / Windows / Linux）

1. 从下方发布附件下载 `antigravity-context-monitor-app-1.17.5.zip`（macOS / Windows / Linux）或 `antigravity-context-monitor-app-1.17.5.tar.gz`（macOS / Linux）。
2. 解压压缩包（得到 `antigravity-context-monitor/` 目录），执行 `agy plugin install ./antigravity-context-monitor`；或直接解压至 `~/.gemini/config/plugins/`（macOS/Linux）或 `%USERPROFILE%\.gemini\config\plugins\`（Windows）。
   - 从源码仓库安装时，也可运行 `npm run compile && node scripts/package-app-plugin.mjs` 后执行 `node scripts/install-app-plugin.mjs --install`（macOS/Linux 可用 `./scripts/install-app-plugin.sh --install`，Windows 可用 `.\scripts\install-app-plugin.ps1 --install`）。
3. 在 Antigravity App 中打开 **Customizations → Installed**（`customization://antigravity-context-monitor`），确认 **Antigravity Context Monitor** 及其 **Context Monitor** Sidecar 已启用（若为覆盖升级请先关闭再重新开启），随后从侧边栏 **`+`** 菜单（`AUX_PANE`）、左侧导航 **Plugins → Context Monitor**（`SIDEBAR`）或 `sidecar://antigravity-context-monitor/context_monitor/` 打开面板。

#### Antigravity IDE（VSIX 扩展 — macOS / Windows / Linux / WSL）

在命令面板（macOS：`Cmd+Shift+P`，Windows / Linux：`Ctrl+Shift+P`）执行 **Extensions: Install from VSIX...** 选择 `antigravity-context-monitor-1.17.5.vsix`（或命令行执行 `antigravity-ide --install-extension antigravity-context-monitor-1.17.5.vsix --force`），重载 IDE 窗口后在扩展详情或**关于**页确认版本为 **1.17.5**。
