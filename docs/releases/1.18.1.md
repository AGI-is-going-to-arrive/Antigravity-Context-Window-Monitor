# v1.18.1 — Context after compaction and recent worker calls

## English

### What changed

- **Context after compaction.** A summarizer reads the old context to create a checkpoint. Overview now marks the resulting context as estimated until a later planner call supplies a measurement. If the available steps are insufficient, the monitor shows an unavailable reading. App and IDE refresh the selected session when its trajectory changes, even if its step count stays the same.
- **Recent model calls.** A worker's call metadata sometimes omits its timestamp. The monitor checks a bounded range of matching planner steps for the original time. The newest verified worker calls can appear at the top of Model Calls while you continue inspecting the root. Records with no reliable date stay undated.
- **Usage & Cost.** Strict pricing excludes saved mapped estimates for unpriced Orchestrator calls. Modern settlements use each model’s recorded usage, call dates and your custom prices. Older settlements that contain only pool totals preserve their saved amount. App and IDE use the ledger day to select historical rates when individual call dates are unavailable.
- **Windows installer.** The PowerShell launcher now detects Node in fresh sessions and forwards local plugin paths containing spaces.

### Install or update

Use the [App installation guide](../../AGENTS.md#english) or install the [IDE VSIX](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/releases/download/v1.18.1/antigravity-context-monitor-1.18.1.vsix). After an App upgrade, turn Context Monitor off and back on in plugin settings. In the IDE, run **Developer: Reload Window** when convenient. To verify downloaded packages locally, compare them with [SHA256SUMS.txt](https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/releases/download/v1.18.1/SHA256SUMS.txt).

The screenshots and walkthrough use synthetic sessions. During normal use, the monitor processes local telemetry that can include prompt metadata, text snippets and checkpoint summaries. Review previews before copying a report or handoff.

### 本次更新

- **压缩后的上下文。** 摘要模型会读取旧上下文以生成检查点。现在，概览在压缩完成后先显示估算值，下一次主模型调用提供新读数后切回实测。如果缺少估算依据，面板显示暂不可用。即使步骤数未变，App 和 IDE 也会在会话轨迹变化后重新读取数据。
- **最近模型调用。** 部分子智能体调用缺少时间戳。插件会在限定范围内查找匹配的步骤，补齐有依据的调用时间。保持主会话选中时，最新子智能体调用也能排到明细顶部。无法核对时间的记录继续保留为空。
- **用量与费用。** 严格计价会排除未定价 Orchestrator 调用以前保存的映射估值。新版结算记录按各模型实际用量、调用时间和自定义单价计算。只有汇总数据的旧账本保留原金额。缺少逐次调用时间时，App 与 IDE 统一按账本日期选择历史费率。
- **Windows 安装。** PowerShell 启动器现在能在新进程中识别 Node，并正确传递包含空格的本地插件路径。
