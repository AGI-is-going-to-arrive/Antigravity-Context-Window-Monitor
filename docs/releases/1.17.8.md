# Release 1.17.8 — Top-Right Status Bar 4-View Popover, Context-Aware Panel Routing, Persistent CDP Launcher UX & Hermetic CDP Tests

## English

### Overview of Changes

- **Top-Right Status Bar 4-View Popover, Local `HH:MM:SS` Clock & Context-Aware `Open Panel` (`CDP_OVERLAY_SCRIPT_VERSION = '1.17.8-r1'` — `src/app/cdp-overlay-assets.ts`, `src/app/sidecar-types.ts`, `src/app/sidecar-runtime.ts`, `src/app/sidecar-server.ts`, `src/app/cdp-injector.ts`, `src/webview-script.ts`):**
  - **Dedicated 4-View Popover (`Quota` / `Context` / `Speed` / `Total`):** Clicking any Top-Right Status Bar metric pill now opens the popover directly on its matching view — **Model Quota Board (`quota`)**, **Context Window (`context`)**, **Speed & Latency (`speed`)**, or **Total Usage & ROI (`total`)** — paired with an interactive 4-segment view switcher inside the popover. Clicking a different metric pill while open smoothly switches views instead of closing, narrow-titlebar `···` overflow menu entries route directly to the clicked metric's view, and update timestamps now render as a readable local `HH:MM:SS` clock instead of raw UTC ISO strings.
  - **8 New Live `CdpOverlayPayload` Telemetry Fields (`buildCdpOverlayPayload()`):** Populated `todayTokens`, `todayCostFormatted`, `cumulativeCostFormatted`, `recordedDaysCount`, `sessionCount`, `peakOutputSpeedTps` (filtering short micro-bursts via `evaluateSpeedSample()`), `recentCallCount`, and `subscriptionRoiSummary` (honoring configured `subscriptionPlan` presets and returning `null` when off) directly from live runtime state (`DailyLedger`, `DailyStore`, `CliUsageScanner`, `GMTracker`, `allTrajectories`, and `estimateSubscriptionRoi()`). Also fixed `getActiveUiGmSummary()` so injected `deps.fetchGM` summaries are never shadowed by an unused fresh `GMTracker`.
  - **Context-Aware `Open Panel` `targetTab` Routing:** Clicking **Open Panel** inside any Top-Right popover view forwards its validated logical `targetTab` (`quota → models`, `context → overview`, `speed → gm`, `total → cost`) across the 256-bit authenticated `POST /api/overlay/action` bridge (`ALLOWED_OVERLAY_TARGET_TABS`) into monotonic snapshot metadata `meta.overlayTargetTab` (`{ seq, tab }`), and `src/webview-script.ts` maps logical tab names (`gm → gmdata`, `sessions → chats`, `cost → pricing`, `accounts → profile`) cleanly while deduplicating stale `seq` values across polls.
- **Persistent CDP Launcher UX, One-Click Reveal & Cross-Platform Hardening (`src/app/cdp-launcher.ts`, `src/app/sidecar-runtime.ts`, `src/webview-panel.ts`, `src/webview-settings-tab.ts`, `src/webview-script.ts`, `src/webview-editorial-styles.ts`, `scripts/install-app-plugin.mjs`):**
  - **macOS foreground dialog & Automation TCC fallback:** Added explicit AppleScript `activate` in `~/Applications/Antigravity (CDP).app/Contents/MacOS/launch` so user confirmation dialogs always surface in front of other windows, plus a clear fallback alert if macOS denies Automation (TCC) permission to quit Antigravity cleanly (`Cmd+Q`).
  - **One-Click `Reveal in Finder / Explorer / Folder` (`#cdpRevealLauncherBtn` / `revealCdpLauncher`):** Added `revealCdpLauncher()` in `src/app/cdp-launcher.ts` and wired `revealCdpLauncher` end-to-end across BOTH Antigravity App Sidecar (`src/app/sidecar-runtime.ts` + `host-bridge.ts`) and Antigravity IDE (`src/webview-panel.ts`), surfacing live `cdpLauncherResult` feedback and synced Settings controls.
  - **Clearer Step 1 / Step 2 guidance, Linux escaping & narrow `<select>` polish:** Clarified bilingual Settings guidance separating launcher creation from launching via the generated launcher, hardened Linux launcher `DEFAULT_BIN` lookup and Freedesktop `.desktop` `Exec=` escaping, and made the Subscription Plan ROI `<select>` responsive so long labels like `Google AI Ultra 20x ($199.99/mo)` never clip in narrow `AUX_PANE` viewports.
- **Hermetic CDP Test Isolation:** Isolated `HOME` / `USERPROFILE` / `APPDATA` / `XDG_CONFIG_HOME` alongside `AGY_BROWSER_ACTIVE_PORT_FILE` in `tests/runtime-v1176-sync.test.ts` so `npm test` always passes 100% hermetically against a real `HOME` even when the user's real `Antigravity (CDP).app` is actively running with a live `DevToolsActivePort`.

核心 `AUX_PANE`、`SIDEBAR` 与**原生面板精简 HUD** 均 100% 原生工作，不依赖 CDP。若您按需启用输入框上下文环或右上角状态条 4 视图悬浮层：

- **推荐方案（一键持久化，永久免疫自动更新丢参）：** 在**设置 → 悬浮层与 CDP** 点击**一键生成持久化启动器**（或运行 `node scripts/install-app-plugin.mjs --setup-cdp-launcher`），自动生成 `~/Applications/Antigravity (CDP).app`（macOS）、桌面与开始菜单 `.lnk`（Windows）或 `~/.local/share/applications/antigravity-cdp.desktop`（Linux），点击设置页的**在访达 / 资源管理器 / 文件夹中显示**即可一键定位。
- **手动终端重启：**
  1. **务必先完全退出 Antigravity App**（macOS 按 `Cmd+Q` 后请等待约 5 秒让后台 `language_server` 彻底清理完成——旧进程尚未退出时执行 `open -a` 会静默忽略 `--args`；Windows / Linux 关闭全部窗口与托盘图标）。
  2. **带 `--remote-debugging-port=0` 参数重新启动：**
     - **macOS（无竞态等待并启动）：** `while pgrep -f '^/Applications/Antigravity\.app/Contents/MacOS/Antigravity($| )' >/dev/null; do sleep 0.5; done; open -a "/Applications/Antigravity.app" --args --remote-debugging-port=0`
     - **Windows（PowerShell）：** `& "$env:LOCALAPPDATA\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Windows（CMD / 快捷方式目标）：** `"%LOCALAPPDATA%\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Linux：** `antigravity --remote-debugging-port=0`
  3. 打开**设置 → 悬浮层与 CDP** 点击**重新检测**。
