# Release 1.17.1 — Orchestrator Carbon and Argon

## English

Orchestrator now appears as **Orchestrator (Carbon)** and **Orchestrator (Argon)** in the IDE. Version 1.17.1 registers both identities throughout model information, context limits, quota grouping, history and custom pricing. The legacy bare name remains a Carbon alias, preserving archived usage and existing custom prices.

### Verified live identities

The running Antigravity IDE catalog was checked on 2026-11-13.

| Role | Placeholder | Catalog ID | Maximum output | Configured worker |
| --- | --- | --- | ---: | --- |
| Orchestrator (Carbon) | `M667` | `gemini-pro-orchestrator` | 262,144 | `M669` |

All three report native context 1,048,576, compression limit 256,000, checkpoint threshold 50,000 and thinking level 3. The startup compression fallback is 255,000 until live metadata arrives. Reported minimum thinking budgets are capability bounds, not fixed request budgets. The worker is not an extra picker entry or an inferred billable call.

The checked account exposes **22 chat entries**: 15 in Gemini (13 ordinary efforts and two Orchestrators), and seven in Claude / GPT. Both coordinators share Gemini quota; percentages are never summed. Availability follows the actual account catalog, including old, partial and empty lists.

Standalone API prices for these three internal models remain unverified. Each has a separate custom-price editor, including before any calls exist. Unknown prices are not zero. Ordinary Carbon/Argon/Hydrogen rates are not inherited. In particular, stripping the `(Argon)` identity must not apply an old custom `Orchestrator` price to Argon. Invalid variants, conflicting response aliases, account switches and model transitions retain strict identity boundaries.
