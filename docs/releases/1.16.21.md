Both identities now have static names, strict aliases, historical/cold-start support, 255,000 startup context fallback, and live 1,048,576 model context / 262,144 output / 256,000 compression / 50,000 checkpoint values. Both report thinking level 3; reported minimum budgets 128 / 32 are not fixed per-request budgets. `plan-execute-config.executionModel` links the coordinator to its configured worker. The real workflow revealed shared execution IDs across multiple calls. Timestamp recovery and embedded metadata enrichment now combine execution and step identity instead of confusing a workflow with one request. The Gemini card lists 14 selectable entries (13 effort variants plus Orchestrator); the hidden worker does not add a picker entry or a separately summed allowance.

No standalone public API price was verified for either internal ID. Both therefore retain explicit unknown pricing and separate custom-rate editors; the Carbon/Hydrogen description does not silently assign those rates, and a configured route does not add a billable call. Actual per-call token counts, including cache reads, remain available.
