# 1.16.20 — Gemini 4 Carbon

Release date: 2026-11-11

## English

Antigravity Context Window Monitor 1.16.20 adds Gemini 4 Carbon Low / Medium / High while retaining Argon, older models, account-specific catalogs, and saved usage history.

### Gemini 4 Carbon

| Effort | Internal ID | Catalog ID | Thinking level |
| --- | --- | --- | ---: |
| Low | `MODEL_PLACEHOLDER_M438` | `gemini-4-carbon-low` | 1 |
| Medium | `MODEL_PLACEHOLDER_M437` | `gemini-4-carbon-medium` | 2 |
| High | `MODEL_PLACEHOLDER_M427` | `gemini-4-carbon-high` | 3 |

The running IDE's `GetUserStatus` and `GetAvailableModels` responses were checked on 2026-11-11. All three tiers report:

- 1,048,576 model-context tokens and **262,144 maximum output tokens**.
- A 256,000 platform compression limit and a separate 50,000 checkpoint threshold. The static context fallback is 255,000 until live metadata arrives.
- Google Gemini provider, thinking enabled, and effort levels 1 / 2 / 3. No fixed per-request thinking budget is inferred.

These are IDE-reported capacities, not public API guarantees. Carbon's output limit is distinct from Argon's 65,536.

Placeholder IDs, catalog IDs, English labels, Chinese effort labels, and labels without parentheses resolve consistently. Family-only `gemini-4-carbon` responses preserve known requested tiers and are not permanently bound to the first observed tier. Carbon and Argon remain separate in GM parsing, historical statistics, and custom pricing.

The release also rejects malformed variants such as `Gemini 4 CarbonHigh`, unmatched parentheses, and unsupported effort names before identity or family-price fallback. Conflicting learned aliases in uppercase/catalog form or with Chinese tier labels cannot overwrite a registered tier.

Carbon shares the Gemini chat quota pool. The tooltip prefers the current model, then a live recommended model, then the newest available generation; within Gemini 4, Carbon precedes Argon. Model cards follow the live account's available list, including an empty list, rather than treating every registered model as available.

### Shared quota pools

Model Quota groups the current 16 chat effort tiers into **two shared-pool cards**. Each lists the model families and effort tiers actually available to the current account:

| Pool | Current member families and efforts | Current tiers |
| --- | --- | ---: |
| Gemini | Carbon, Argon, Flash: Low / Medium / High each | 9 |
| Claude / GPT | Opus, Sonnet: Low / Medium / High each; GPT-OSS: Medium | 7 |

The live status reports matching remaining fractions and reset times within each of these pools. Percentages are not summed or averaged. If member data differs, the UI retains ranges and per-model details; missing data stays explicitly unknown. Unknown models and image-generation identities remain separate from the two known chat pools. Model Info, GM call statistics, and pricing preserve every effort tier's identity.

Final installed-plugin acceptance of the shared-pool UI is pending. The About compatibility note targets plugin 1.16.20, IDE 2.6.0, and 2026-11-11; its packaged rendering is included in that acceptance.

### Pricing

The [Google AI Studio Standard API pricing table](https://aistudio.google.com/docs/pricing#gemini-4-carbon), verified 2026-11-11, specifies these Carbon rates for all three effort tiers, in USD per million tokens:

| Call date (UTC) | Input | Output, including thinking | Implicit cache reads |
| --- | ---: | ---: | ---: |
| Through 2026-11-30 | $2.00 | $10.00 | $0.10 |
| From 2026-12-01 | $4.00 | $20.00 | $0.20 |

The [Google launch announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/) corroborates the input/output rates and cutover date. Pricing follows each call's UTC timestamp; saved archival costs and custom family/tier overrides keep precedence. Carbon and Argon have independent pricing identities even though their published rates match. Only implicit caching is supported, with no explicit cache-write charge. These are Standard API estimates, not Antigravity subscription charges, credits, or Batch/Flex/Priority prices. Unknown-model prices remain explicitly unavailable rather than free.

### Install

Install `antigravity-context-monitor-1.16.20.vsix` through **Extensions: Install from VSIX...**, reload the existing Antigravity IDE window, and confirm **1.16.20** in extension details. Open **Models → Model Info** to inspect Carbon's three effort cards and **Output → Antigravity Context Monitor** for diagnostics. Use `Cmd+Shift+P` on macOS or `Ctrl+Shift+P` on Windows/Linux to open the command palette.

Placeholder ID、catalog ID、英文标签、中文档位名及无括号标签均一致解析。仅含 `gemini-4-carbon` 家族名的响应保留已知请求档位，不会永久绑定最先观测到的档位。Carbon 与 Argon 在 GM 解析、历史统计和自定义计价中保持独立。

Carbon 共用 Gemini 聊天配额池。Tooltip 依次优先当前模型、实时推荐模型和最新可用世代；Gemini 4 内 Carbon 排在 Argon 前。模型卡片以当前账号实时可用列表为准，包括空列表，不将静态注册等同于当前可用。
