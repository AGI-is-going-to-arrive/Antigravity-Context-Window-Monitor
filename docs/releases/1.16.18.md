# 1.16.18 — Claude 5.5 Support and Refined Model Cards

Release date: 2026-10-03

## English

Antigravity Context Window Monitor 1.16.18 supports Claude Opus 5.5 and Claude Sonnet 5.5 in Low, Medium, and High modes. The model-information cards now use neutral IDE theme colors and clear metric rows, with the compression limit presented alongside the native context and thinking state.

### Models and account compatibility

| Model | Low | Medium | High |
| --- | --- | --- | --- |
| Claude Opus 5.5 | `MODEL_PLACEHOLDER_M400` | `MODEL_PLACEHOLDER_M401` | `MODEL_PLACEHOLDER_M402` |
| Claude Sonnet 5.5 | `MODEL_PLACEHOLDER_M403` | `MODEL_PLACEHOLDER_M404` | `MODEL_PLACEHOLDER_M405` |

The corresponding catalog IDs are `claude-opus-5-5-{low,medium,high}` and `claude-sonnet-5-5-{low,medium,high}`. A metadata-only probe of the running Antigravity IDE on 2026-10-03 verified these six entries without sending generation requests. Each reports:

- 1,000,000-token native context and 128,000-token maximum output.
- A 256,000-token platform compression limit; the offline/static fallback is 255,000.
- A separate internal checkpointer `tokenThreshold` of 50,000.
- Adaptive thinking with effort levels 1 / 2 / 3. The API does not specify a fixed thinking-token budget.

The registry, context tracking, localized names, quota pools, pricing lookup, and saved usage share these identities. Family-only response names do not overwrite a known effort tier.

Claude 4.6 remains supported for accounts that still expose it and for historical records. Paid Pro/Ultra accounts may expose 5.5 while some unpaid accounts retain 4.6; Gemini-only accounts are also supported. The Models tab uses the current account's live picker. It does not infer availability from a plan name or implement a date-based removal rule, so upstream changes in third-party access do not require deleting historical model support.

### Model information UI

- Replaces colored threshold badges and glow backgrounds with neutral theme surfaces, subtle borders, and aligned metric rows.
- Distinguishes the platform compression limit from the model's native context window.
- Shows readable provider names and full, wrapping model IDs, with internal IDs retained for diagnostics.
- Labels adaptive, dynamic, and fixed-budget thinking accurately; missing metadata is shown as unavailable.
- Supports English, Chinese, bilingual display, narrow panels, light/dark themes, and high-contrast themes. Number formatting follows the chosen UI language.

### Pricing

The [official API prices](https://platform.claude.com/docs/en/about-claude/pricing) for both Claude 5.5 families are listed below as a reference, in USD per million tokens (2026-10-03):

| Model | Input | Output | Cache read | Cache write, 5 min | Cache write, 1 hour |
| --- | --- | --- | --- | --- | --- |
| Claude Opus 5.5 | $4 | $20 | $0.20 | $5 | $8 |
| Claude Sonnet 5.5 | $2 | $10 | $0.20 | $2.50 | $4 |

The built-in cache-write reference rate is for **5 minutes**. Current cost estimates exclude cache creation fees because telemetry does not reliably identify creation tokens and their TTL; 1-hour write fees are not added automatically either. Reported cache-read tokens are included. Raw usage is retained, and custom rates remain available. All estimates are API equivalents, not Antigravity subscription charges.

### Refresh and editing fixes

A successful response with an empty picker now clears the previous account's visible model list. Live catalog IDs are preserved, and pricing cannot fall back across model generations. Polling preserves price drafts, including when a first call appears for another effort tier in the same family. Invalid prices are blocked from saving, while pause/resume keeps the label, ARIA state, and visible indicator in sync.

### Install

Install `antigravity-context-monitor-1.16.18.vsix` using **Extensions: Install from VSIX...** in Antigravity IDE, then reload the window. Confirm version **1.16.18** in the extension details and open the **Models** tab.

### 模型信息界面

- 将彩色阈值徽标和光晕背景替换为中性主题背景、细边框和对齐的数据行。
- 明确区分平台压缩上限与模型原生上下文窗口。
- 显示易读的提供商名称及可换行的完整模型 ID，同时保留内部 ID 供诊断。
- 准确呈现自适应、动态及固定预算思考；缺失元数据时显示暂无数据。
- 支持中文、英文、双语、窄面板、亮色/暗色及高对比度主题；数字格式跟随所选界面语言。
