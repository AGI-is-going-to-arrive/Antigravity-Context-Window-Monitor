# Release 1.17.2 — Studio Telemetry Ledger, Speed/TTFT/Cache Telemetry & Neon Models

## English

### Overview of Changes

- **Model generation speed (`tok/s`), TTFT (Cached vs Uncached) & First-Token / Prompt Cache telemetry:** Added pure, zero-VS Code/DOM telemetry engine `src/telemetry-metrics.ts` built on verified Antigravity protobuf semantics: decode-only `streamingSeconds` (excluding `ttftSeconds`), additive prompt total `totalPromptTokens = inputTokens + cacheReadTokens + cacheCreationTokens`, inclusive `outputTokens` (separating explicit and Gemini implicit thinking into visible response speed without double-counting), ratio-of-sums time-weighted throughput (`sum(output) / sum(stream)`), two-gate noise filters (`≥ 0.05s & ≥ 2 tokens` hard validity; `≥ 0.25s & ≥ 10 tokens` representative spread), Cached vs Uncached TTFT speedup comparison (`ttftCacheDeltaPct`), R-7 `p50`/`p95` quantiles, conservative compaction-call filtering (`isInternalCompactionCall()`), and unpriced USD savings guards (`estCacheSavingsUsd: number | null`, never fake `$0.00`).
- **Telemetry surfaced across Overview, GM Data, Calendar & Status Bar / Hover:**
  - **Overview (`src/webview-overview-tab.ts`, `src/monitor-overview.ts`):** Compact 4-cell L2 inset strip (`.overview-telemetry-strip`, cleanly omitted when idle/disconnected/empty) showing Speed (`tok/s` + `resp` / `avg`), adaptive TTFT (`cached` / `p50`), token-weighted Cache Hit (`%`, volume + `X/Y` calls), and Cache Saved (`$USD` when priced else compact `tokens` + Warm/Warming/Cold warmth state).
  - **GM Data (`src/activity-panel.ts`):** Account-filtered KPI strip cells (**Speed**, **Avg TTFT**, token-weighted **Cache Hit**); dedicated 2-column **Speed & First-Token Cache Ledger** (`#telemetryLedgerSection`) featuring weighted/latest/median/min–max/visible `tok/s`, proportional **Cached vs Uncached TTFT** comparison bars with speedup delta pill and `p50`/`p95`/`Avg Stream` footer, plus token-weighted Cache Hit hero, warmth badge, 3-segment Prompt Cache bar (`Cache Read` | `Fresh Input` | `Cache Write`), and 3-row cache/savings ledger; unified `Calls`-first per-model cards with Speed, valid-sample TTFT, token-weighted Cache Hit, and Cache Write; and per-step / per-turn timeline telemetry pills.
  - **Calendar (`src/webview-calendar-tab.ts`):** Day-detail breakdown chips now show archived time-weighted generation speed (`.cal-chip-speed`), adaptive `avgTTFT`, and token-weighted `tokenCacheHitRate` (with graceful legacy `cacheHitRate` fallback).
  - **Status Bar, Hover & Settings (`src/statusbar.ts`, `src/webview-settings-tab.ts`, `package.json`):** Added opt-in default-off `statusBar.showSpeed` (`#toggleSpeed`) and `statusBar.showCacheHit` (`#toggleCacheHit`) settings (hidden on cold start — never flashing `0 tok/s` or `0%`) alongside a `---`-separated hover telemetry block across `compact`, `auto`, and `full` densities.
- **GM, Activity & v1-compatible persistence bug fixes:** Added optional sample-count fields (`ttftSampleCount`, `streamingSampleCount`, `timedOutputTokens`, `timedStreamingSeconds`, `cacheHitCalls`) to `GMModelStats` (`src/gm/types.ts`, `src/gm/summary.ts`, `src/gm/tracker.ts`) fixing zero-TTFT/zero-streaming dilution on merge and deduplicating `src/activity/helpers.ts` `mergeGMStats()`; preserved `gmResponseTokens` and `gmCacheCreationTokens` on `StepEvent`; aligned GM Data KPI totals with account-filtered summaries; and extended `DailyLedger` → `DailyArchival` → `DailyStore` with backward-compatible optional v1 timing and cache-token persistence (`LedgerModelTelemetry`, `LedgerModelStats`, `LedgerRecordedCall`, `GMModelCycleStats`) so daily rollovers and `backfillMissingCosts()` preserve timing and cache reads without breaking legacy v1 records.
- **Modern Editorial Telemetry ("Studio Telemetry Ledger") UI redesign across all 9 tabs:** Rebuilt the monitor panel visual architecture in `src/webview-editorial-styles.ts` and `src/webview-styles.ts` with a cool studio-neutral 4-tier surface system — **Obsidian Slate Dark** (`#0D1014` / `#14181F` / `#1B212B`), **Alabaster Studio Light** (`#FAFBFC` / `#FFFFFF` / `#F2F4F8`), and native VS Code **High-Contrast** pass-through tokens. Eliminated warm sepia/brown tints, legacy 3px rainbow left-border strips, decorative animations, and unsupported `backdrop-filter` blur.
