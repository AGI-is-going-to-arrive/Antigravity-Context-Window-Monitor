# Release 1.17.9 — TopBar 4-Tier Anchoring, Top Layer Popovers, Sidebar-Safe Clamping & Composer Ring `Turbo` Anchoring

## English

### Overview of Changes

- **Top-Right Status Bar 4-Tier Anchoring, Sidebar-Safe Insets & Free-Space Budgeting (`CDP_OVERLAY_SCRIPT_VERSION = '1.17.9'` — `src/app/cdp-overlay-assets.ts`):**
  - **Fixed collapsed-sidebar overlap over macOS traffic lights, sidebar toggle, back/forward & search controls:** Removed the tree-order comma selector `[data-testid="pane-titlebar-toolbar"], [class*="@container/titlebar"]` (which matched the parent `@container/titlebar` at `x=0` over left window chrome when the sidebar collapsed) and the broken `div.absolute.right-0.top-0` selector (which matched invisible `.agy-hover-actions`). Replaced with a strict 4-tier `findTopBarAnchor()` (`toggle-aux-sidebar` before `toggle-maximize-pane` → Windows/Linux `window-controls-reserve` → standalone visible non-hover `pane-titlebar-toolbar` → `fixed` top-right with WCO spacer and non-double-subtracted `host`/`cluster` `maxWidth` safe insets clearing left chrome).
  - **Live re-anchoring & accurate free-space budgeting:** Removed the sticky `isConnected` early return in `anchorTopBarHost()` so TopBar automatically re-anchors into Antigravity's Right Chrome Overlay (`z-50`, outside `agy-sheet`) when navigating from Settings/New Conversation into a conversation; added `:host { flex-shrink: 0 }` and live free-space budgeting (`applyTopBarResponsiveLayout()`) that keeps all 4 pills visible when `AUX_PANE` has wide drag-spacer room and collapses cleanly without self-width feedback loops.
- **Top Layer Popovers (`popover="manual"`), Sidebar-Aware Clamping & Dynamic Transition Observers (`src/app/cdp-overlay-assets.ts`):**
  - **Escaped `agy-sheet` (`z:0; overflow:hidden`) stacking-context clipping/occlusion:** Promoted `.acm-quota-popover`, `.acm-overflow-menu`, and Composer `.acm-popover` into Chromium's **Top Layer** via `popover="manual"` + `inset: auto; margin: 0;` + safe `openTopLayerPopover()`/`closeTopLayerPopover()` helpers so popovers paint above `agy-sheet`, the left sidebar (`z:10`), resize sashes (`z:30`), chrome overlays (`z:50`), and `AUX_PANE` iframes.
  - **Sidebar-aware clamping & live sync:** Upgraded `positionPopoverNear()` with live `getOpenSidebarRightPx()` horizontal clamping (`sidebarRight + 8` when the main viewport fits, falling back cleanly to `10px` in Top Layer on ultra-narrow windows), steady `r.cluster` anchoring across all 4 tabs (`Quota` / `Context` / `Speed` / `Total`), and vertical clamping. Added `ResizeObserver` (`.agy-sheet`, sidebar outer, `aux-pane-split`, `data-side-panel-strip`), layout-attribute `MutationObserver` (`data-sidebar-closed`, `data-side-panel-docked`, `data-side-panel-maximized`, `data-pane-unfocused`, `aria-expanded`, `hidden`), and `transitionend` listeners with complete cleanup on `unmount('all')`.
- **Composer Context Ring Anchoring Left of `Turbo` & HTTPS Hub Target Selection (`src/app/cdp-overlay-assets.ts`, `src/app/cdp-injector.ts`):**
  - **Fixed misplacement next to `This Computer` on New Conversation:** Removed the legacy metadata bar `[data-testid="input-box-bottom-toolbar"]` (`This Computer` / project / git branch) from Tier 2 composer footers, explicitly blacklisted metadata bars (`location-selector-trigger` / `project-selector-trigger` without `permissions-selector-trigger`, while never misclassifying outer `surface-composer`), and switched `findComposerAnchor()` to strict global tiering preferring visible focused panes (`[data-pane-unfocused]` awareness) with 64-level ancestor visibility checks (`isElementVisible()`).
  - **Preset, i18n, icon-only & wrapper resilience:** Expanded approval-mode matching (`Request Review`, `Default`, `Auto`, `Turbo`, Chinese labels, `aria-label`, and `<400px` icon-only `[data-testid="permissions-selector-trigger"]`), added `input-cancel-button` & mic fallbacks walking up out of `span[data-testid="voice-live-pill"]` into `rightGroup`, removed sticky `isConnected` early return in `anchorComposerHost()`, and hardened `:host { flex-shrink: 0 }` + `.acm-ring-trigger { margin-right: 2px }`.
  - **Fixed HTTPS Hub target title self-exclusion (`src/app/cdp-injector.ts`):** Updated `isExcludedSidecarOrDevToolsTitle()` so real HTTPS Antigravity/Jetski Hub windows (`... - Antigravity`) are never excluded when the active workspace or conversation title contains `"antigravity context monitor"` or `"swarm"`.

#### 面板内一键自更新与手动压缩包安装（Antigravity App）

1. **面板内自更新（v1.17.6+）：** 打开**设置 → 更新**或**关于 → 版本与更新**，点击**检查更新**并点击**立即升级**。原子替换完成后，打开 `[Antigravity Context Monitor](customization://antigravity-context-monitor)` 将插件**关闭再重新开启**即可安全加载新运行时（绝不强杀正在运行的 Antigravity 会话）。
2. **手动压缩包安装：** 下载 `antigravity-context-monitor-app-1.17.9.zip`（macOS / Windows / Linux）或 `antigravity-context-monitor-app-1.17.9.tar.gz`（macOS / Linux）与 `SHA256SUMS.txt`，核对 SHA-256 后解压得到 `antigravity-context-monitor/` 并执行 `agy plugin install ./antigravity-context-monitor`（或直接解压至 `~/.gemini/config/plugins/` 或 `%USERPROFILE%\.gemini\config\plugins\`）。

#### 可选 CDP 桌面悬浮层与一键持久化启动器（严格按需开启，零二进制修改）

核心 `AUX_PANE`、`SIDEBAR` 与**原生面板精简 HUD** 均 100% 原生工作，不依赖 CDP。若您按需启用输入框上下文环或右上角状态条 4 视图悬浮层：

- **推荐方案（一键持久化，永久免疫自动更新丢参）：** 在**设置 → 悬浮层与 CDP** 点击**一键生成持久化启动器**（或运行 `node scripts/install-app-plugin.mjs --setup-cdp-launcher`），自动生成 `~/Applications/Antigravity (CDP).app`（macOS）、桌面与开始菜单 `.lnk`（Windows）或 `~/.local/share/applications/antigravity-cdp.desktop`（Linux），点击设置页的**在访达 / 资源管理器 / 文件夹中显示**即可一键定位。
- **手动终端重启：**
  1. **务必先完全退出 Antigravity App**（macOS 按 `Cmd+Q` 后请等待约 5 秒让后台 `language_server` 彻底清理完成——旧进程尚未退出时执行 `open -a` 会静默忽略 `--args`；Windows / Linux 关闭全部窗口与托盘图标）。
  2. **带 `--remote-debugging-port=0` 参数重新启动：**
     - **macOS（无竞态等待并启动）：** `while pgrep -f '^/Applications/Antigravity\.app/Contents/MacOS/Antigravity($| )' >/dev/null; do sleep 0.5; done; open -a "/Applications/Antigravity.app" --args --remote-debugging-port=0`
     - **Windows（PowerShell）：** `& "$env:LOCALAPPDATA\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Windows (CMD / 快捷方式目标)：** `"%LOCALAPPDATA%\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=0`
     - **Linux：** `antigravity --remote-debugging-port=0`
  3. 打开**设置 → 悬浮层与 CDP** 点击**重新检测**。

#### Antigravity IDE（VSIX 扩展 — macOS / Windows / Linux / WSL）

下载 `antigravity-context-monitor-1.17.9.vsix`（对照 `SHA256SUMS.txt` 校验 SHA-256），在命令面板（`Cmd+Shift+P` / `Ctrl+Shift+P`）执行 **Extensions: Install from VSIX...**，或命令行运行：

```bash
antigravity-ide --install-extension antigravity-context-monitor-1.17.9.vsix --force
```

重载 IDE 窗口，在扩展详情或**关于**页确认版本号为 **1.17.9**（亦可从 [Open VSX](https://open-vsx.org/extension/AGI-is-going-to-arrive/antigravity-context-monitor) 获取更新）。
