### Installation & Upgrade

#### One-Sentence AI Agent Install / Upgrade (`AGENTS.md` — Recommended)

Paste this prompt to any AI coding agent:

> Read `AGENTS.md` in `https://github.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor` and install/upgrade Antigravity Context Monitor for my Antigravity App.

Or run the zero-clone installer directly (verifies `SHA256SUMS.txt` automatically):
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs -o /tmp/acm-install.mjs && node /tmp/acm-install.mjs --from-github && rm -f /tmp/acm-install.mjs`
- **Windows (PowerShell):** `$f = Join-Path $env:TEMP 'acm-install.mjs'; irm 'https://raw.githubusercontent.com/AGI-is-going-to-arrive/Antigravity-Context-Window-Monitor/main/scripts/install-app-plugin.mjs' -OutFile $f; node $f --from-github; Remove-Item $f -Force`
- **From a local clone:** `node scripts/install-app-plugin.mjs --upgrade` (or `./scripts/install-app-plugin.sh --upgrade` / `.\scripts\install-app-plugin.ps1 --upgrade`), then verify with `node scripts/install-app-plugin.mjs --status --check-remote`.

#### In-App Self-Upgrade & Manual Archive Install (Antigravity App)

1. **In-App Self-Upgrade (v1.17.6+):** Open **Settings → Updates** or **About → Version & Updates**, click **Check for Updates**, then **Upgrade Now**. After the verified atomic swap completes, open `[Antigravity Context Monitor](customization://antigravity-context-monitor)` and toggle the plugin **Off → On** safely (never kill a running Antigravity session).
2. **Manual Archive Install:** Download `antigravity-context-monitor-app-1.17.6.zip` (macOS / Windows / Linux) or `antigravity-context-monitor-app-1.17.6.tar.gz` (macOS / Linux) plus `SHA256SUMS.txt`, verify the SHA-256 digest, extract (`antigravity-context-monitor/`), and run `agy plugin install ./antigravity-context-monitor` (or extract directly into `~/.gemini/config/plugins/` or `%USERPROFILE%\.gemini\config\plugins\`).

#### Antigravity IDE (VSIX Extension — macOS / Windows / Linux / WSL)

Download `antigravity-context-monitor-1.17.6.vsix` (verify SHA-256 against `SHA256SUMS.txt`), then run **Extensions: Install from VSIX...** (`Cmd+Shift+P` / `Ctrl+Shift+P`) or:

```bash
antigravity-ide --install-extension antigravity-context-monitor-1.17.6.vsix --force
```

Reload the IDE window and confirm **1.17.6** in extension details or **About** (also available via [Open VSX](https://open-vsx.org/extension/AGI-is-going-to-arrive/antigravity-context-monitor)).
